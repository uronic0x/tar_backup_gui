# Security Policy | 安全策略

## Reporting a Vulnerability | 报告漏洞

- English: Open a private security advisory on GitHub (Security → Report a vulnerability), or contact the maintainer via GitHub.
- 简体中文：请通过 GitHub 的私密安全公告（Security → Report a vulnerability）联系维护者，请勿在公开 Issue 中讨论漏洞细节。

## Scope | 范围

This is a local backup tool. It does not transmit data over the network and stores no credentials.
本项目为本地备份工具，不进行网络传输，不存储任何凭据。
